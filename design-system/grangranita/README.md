# Дизайн-система «Грань Гранита»

Документация и HTML-kit по живому сайту [grangranita.ru](https://grangranita.ru/) (мастерская памятников, Орехово-Зуево). Снято в сентябре 2026: HTML/CSS продакшена + скриншоты desktop 1440 и mobile 390.

Это **не** документация MODX. Каталог лежит отдельно от `ru/` / `en/`, чтобы не попасть в сборку docs.modx.pro.

## Как открыть примеры

```bash
python3 -m http.server 8765 --directory design-system/grangranita
```

Дальше: http://127.0.0.1:8765/examples/

Шрифт продакшена — **DIN Pro Condensed** (коммерческий, в репозиторий не кладём). В kit — Barlow Condensed + Source Sans 3 как свободная замена.

## Принципы (как сайт себя ведёт)

1. **Светлый холст `#f5f5f5`, чёрный гранит, мало цвета.** Золото `#a56b00` есть только у выделения текста — его стоит сделать акцентом.
2. **Два мира графики:** акварель на главной vs чёрные силуэты в каталоге моделей vs реальные фото монтажа.
3. **Мемориальный тон.** Промо-лента «РАССРОЧКА» и салатовая кнопка 36px спорят с спокойной витриной.
4. **Контейнер 1400px**, сетки 3 / 5 колонок, BEM (`header`, `catalog-card`, `hero__button`).
5. Стек сайта: MODX + Tailwind-сборка `output.css` + Splide + Alpine + FetchIt.

## Быстрый старт для агента

1. Прочитать этот README и `IMPROVEMENTS.md`.
2. Сверить токены, не вводить новый зелёный/синий.
3. Открыть URL или kit в браузере, снять desktop + mobile, потом править код.
4. Не копировать весь `output.css` — только переменные и паттерны.
